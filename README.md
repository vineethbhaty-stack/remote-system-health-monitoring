Remote System Health Monitoring

1.Project Description
This project monitors the health of multiple systems
using Python socket programming and Mininet.

2. Objectives
- Monitor CPU usage.
- Monitor memory usage.
- Monitor process information.
- Monitor network statistics.
- Display monitoring information at a central server.

3.Technologies Used
- Python
- UDP Socket Programming
- Mininet
- Open vSwitch
- SDN Controller
- Ubuntu
- GitHub

4. Project Files
- server.py - Monitoring server
- agent.py - Monitoring agent
- topology.py - Mininet topology
